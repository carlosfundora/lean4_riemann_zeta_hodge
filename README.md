# Lean 4: Riemann, Zeta and Hodge

Carlos Fundora’s mathematical formalization project, focused on the Riemann hypothesis, zeta-function results, the Hodge conjecture, the Birch–Swinnerton-Dyer conjecture and related mathematics.

## Project status

Work in progress. This repository is a fork of the Lean 4 compiler repository and is intended to host future proof projects. It does not currently present completed proofs of the Riemann, Hodge or Birch–Swinnerton-Dyer conjectures. Project proof sources have not yet been uploaded.

## Proof organization

The [proofs directory](proofs/) will contain one subdirectory per individual proof, named after that proof rather than a broad mathematical topic. Proof subdirectories and source uploads are currently on hold. Reproducible build instructions and pinned dependencies will accompany proof projects when released; the upstream instructions below describe Lean itself.
